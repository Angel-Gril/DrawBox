About DrawBox

一个轻量的提示词仓库

浏览、搜索、收藏和复制，全部在浏览器里完成。

DrawBox 是一个纯静态 AI 图像提示词画廊。项目不依赖后端数据库，所有页面与数据都能直接部署到 GitHub Pages。

主要功能

  • 分类与搜索：按大分类、小分类筛选，也可以搜索标题、正文和标签。
  • 完整正文：列表使用轻量数据，详情按需加载完整提示词。
  • 本地收藏：收藏数据保存在浏览器 localStorage，不需要账号。
  • 深色模式：跟随站点主题切换，偏好同样保存在本地。

图片如何加载

主站只保存页面、JSON 数据和图片索引，不把全部原图塞进一个 GitHub 仓库。图片按配置分散到多个 GitHub Pages 图片仓库，浏览器会根据路径映射请求对应仓库。

图片仓库和映射在 js/config.js 与 data/image-map.json 中维护。项目附带分片脚本，可以按容量把本地原图分配并复制到多个仓库目录。

部署方式

主站是普通静态文件，开启 GitHub Pages 后即可访问。图片仓库同样开启 Pages，并在配置里填写 GitHub Pages 域名和仓库列表。每个图片仓库独立计算站点容量与流量。

本地数据

DrawBox 不上传收藏、不记录登录状态，也不依赖第三方接口。清除浏览器站点数据会同时清除主题与收藏记录。

内容说明

本项目用于个人学习、浏览与备份。使用提示词或图片时，请遵守内容各自适用的许可与平台规则，不要将本站内容直接宣称为自己的原创作品。
